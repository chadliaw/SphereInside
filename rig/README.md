# 拍攝支架

讓手機繞著鏡頭旋轉的雙軸支架：水平旋轉的鉛直軸與俯仰的水平軸交會在鏡頭上，轉動時鏡頭的位置不變，照片之間就不會有視差。

> **這個模型還沒有實際列印過。** 尺寸與干涉已用程式檢查，但配合的鬆緊、強度與手感都需要列印後調整。

| [stl/arm.stl](stl/arm.stl) | 水平臂與立柱 | 120 × 207 × 34 | 側躺 |
| [stl/cradle.stl](stl/cradle.stl) | 俯仰座與橫桿 | 154 × 78 × 28 | 背面朝下 |
| [stl/jaw_a.stl](stl/jaw_a.stl) | 夾爪（靠俯仰座一側） | 17 × 21 × 28 | 凸緣朝下 |
| [stl/jaw_b.stl](stl/jaw_b.stl) | 夾爪（另一側） | 17 × 21 × 28 | 凸緣朝下 |

STL 已經擺成列印的方向，都不需要支撐。水平臂長 207 mm，列印床至少要有 210 mm。[rig.step](rig.step) 是組裝後的樣子，可以用 CAD 軟體開啟。

建議用 PETG 或 PLA，外牆 4 圈以上、填充 30% 以上；定位彈片靠材料的彈性運作，不要用太脆的材料。

## 組裝

1. **腳架螺帽**：把 1/4" 螺帽從底座上表面的六角孔放到底。
2. **水平軸**：M8 × 35 螺栓從水平臂上表面的六角沉孔穿下去，穿過底座。軸承從底座下方套上螺栓、壓入軸承座，再加墊圈與防鬆螺帽。
3. **俯仰軸**：M8 × 40 螺栓從俯仰座內側的六角沉孔穿出，穿過立柱。軸承從立柱外側套上螺栓、壓入軸承座，再加墊圈與防鬆螺帽。
4. **調整鬆緊**：螺帽鎖到轉動時有阻力、放手後不會自己轉動為止。兩個轉軸都靠列印件之間的平面互相貼合來保持穩定，軸承只負責定心。
5. **夾爪**：M4 螺帽放進夾爪的六角孔，夾爪的凸緣勾在橫桿上緣，M4 螺絲加墊圈從橫桿背面穿過滑槽鎖進去。
6. **裝上腳架**：把腳架的螺絲鎖進底座的螺帽。腳架螺孔不在轉軸正下方，這不影響拍攝。

## 對準鏡頭

支架的重點是讓鏡頭落在兩軸的交點上，每支手機第一次使用時要調一次：

1. 手機直放、螢幕朝自己、機背貼在橫桿上。鏡頭通常靠近俯仰座的那一側。
2. 從背面看，橫桿上有一條鉛直的刻線，俯仰座上有一條水平的刻線。
3. 左右移動兩個夾爪，讓鏡頭在橫桿刻線的正上方。
4. 上下移動手機，讓鏡頭與俯仰座的刻線等高。
5. 鎖緊兩個夾爪。

檢查方式：對著一近一遠、前後重疊的兩個物體，轉動支架。如果兩者的相對位置不變，鏡頭就對準了。

多鏡頭的手機要對準實際用來拍攝的那一顆，也就是拍攝網頁使用的主鏡頭。

## 適用的手機

| 項目 | 範圍 |
| --- | --- |
| 鏡頭到靠近俯仰座的機身側邊 | 10–40 mm |
| 鏡頭到另一側的機身側邊 | 20–75 mm |
| 鏡頭到機身底端 | 145 mm 以下 |
| 機身厚度（含保護殼） | 約 5–13 mm |

超出範圍時可以修改 [build_rig.py](build_rig.py) 開頭的尺寸後重新產生；例如 `SWING` 是鏡頭到機身底端的最大距離，它決定立柱的高度。

## 使用

- **水平**：底座外緣有 12 個凹槽，每 30° 一格，轉動時彈片會卡入定位。
- **俯仰**：沒有定位點，轉到需要的角度後靠轉軸的阻力停住。仰角由手機的重力感測得出，比羅盤準確。
- **正下方**：朝下拍時會拍到支架與腳架，這無法避免。

## 重新產生模型

```
pip install cadquery
python rig/build_rig.py
```

程式會先檢查零件之間、以及俯仰到各個角度時手機與支架之間有沒有干涉，再輸出檔案。

## 已知的疑慮

- **每個轉軸只有一個軸承。** 單一軸承擋不住歪斜，所以設計上靠列印件的平面貼合來支撐。如果晃動太大，可能要加大貼合面或改成每軸兩個軸承。
- **立柱上的軸承座是橫著列印的。** 圓孔的頂部可能下垂，軸承壓不進去時需要稍微修磨。
- **腳架螺帽下方只有 1.6 mm。** 腳架螺絲只凸出約 4.5 mm，這層不能再厚；不要鎖得太用力。
- **餘量是估計值。** 軸承座的餘量是 `BEARING_FIT`，太緊或太鬆時調整它。
